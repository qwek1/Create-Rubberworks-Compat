# Create-Rubberworks-Compat
Modifies recipe from Create Addons to use Rubber Sheets instead of Dried Kelp

Create: Rubberworks is a mod that replaces Dried Kelp in Create Recipes with rubber, by default Create Addons recipes are not supported so you will need this datapack for Create Addons recipes to also use Rubber Sheets or use your own datapack / kubejs to modify recipes.

I had originally only made this for my modpack All of Create but im sure there are a lot of existing modpacks and people that would want something like this that may not know how to so I decided to share it, enjoy! If you have any suggestions or mods that aren't supported just let me know in comments or messages and ill add support.

Supported Mods:
- Create Aeronautics
- Create: Diesal Generators
- Create Encased
- Create: Electro Energetics
- Create: Fantasizing Again
- Create: Hypertubes
- Create: Power Grid
- Create : Misc & Things
